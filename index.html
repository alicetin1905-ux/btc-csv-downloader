How it works

The page downloads public BTCUSDT linear-perpetual candles directly from Bybit. No API key is required. The downloader works backwards through the available candle pages instead of stopping after the newest 1,000 candles. Strategy components used in this version:

• Chandelier Exit — ATR 4 / multiplier 2
• ZLSMA — length 38
• MACD — 5 / 35 / 5
• Long / short momentum confirmation
• Risk-based position sizing
• SL + TP1 + TP2 + TP3
• ZLSMA exit
• Equity and drawdown calculation

This is a research/backtesting tool, not an execution engine.
